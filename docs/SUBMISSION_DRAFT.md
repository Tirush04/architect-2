## Why would a non-technical user pick your platform?
*(Someone who already uses Replit, Lovable or Emergent.)*

- You approve a plan before anything is built. Architect writes a plain-English Blueprint (pages, data, and what each agent does and when), and you edit it like a document. Nothing gets coded until you say go.
- It's never a black box. Every change comes with a short "what changed" summary and a saved version you can restore in one click. Nothing is ever deleted.
- You can point and tell. Click anything in the preview and describe the change in your own words.
- Agents are visible, not magic. Each one is a simple flow: what starts it, what it does, which tools it uses, and where a human has to approve. You can test it with a sample message and see every step before it goes live.
- Going live is one button. A checklist, a live link, and one-click rollback if something looks wrong.
- When you need an engineer, they open the same project in the Pro view. No export, no rebuild.

## Why would a technical user pick your platform?
*(Someone who already uses Claude Code, Codex or Cursor.)*

- Agents are real code in the framework you already use: Lyzr ADK, LangGraph, CrewAI, OpenAI Agents SDK, Claude Agent SDK or AutoGen. Switch frameworks in one click and the code regenerates. There's no proprietary config to escape from.
- It works like a normal repo: file tree, a real code editor, a diff of every change against any earlier version, and pushes to GitHub as ordinary commits. You can also import an existing repo, and Architect maps its structure and detects the stack.
- A structured plan comes before generation, so you stop burning turns re-explaining the app in chat.
- It's safe by default. Generated apps run sandboxed, secrets are encrypted, and API keys with a REST API are live today. A CLI and MCP access for Claude Code and Cursor are designed as the next step.
- Deploy and rollback are built in, and business stakeholders can change copy and flows in the Guided view without filing tickets.
